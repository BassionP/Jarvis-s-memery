# Jarvis-s-memery

Hermes 记忆备份仓库（**私有**）。

## 文件说明

| 文件 | 内容 |
|------|------|
| `MEMORY.md` | 工作笔记（环境、约定、经验教训） |
| `USER.md` | 用户画像（身份、偏好、环境） |
| `hermes-memory-export-YYYYMMDD.md` | 合并导出快照（含时间戳） |

## 说明

- 源文件位于 `~/.hermes/memories/`（MEMORY.md + USER.md），由 Hermes 记忆系统自动维护。
- 本仓库用于备份/同步记忆，`MEMORY.md` 内各条目以 `§` 分隔。
- 内容含个人及工作敏感信息，请保持仓库私有。
